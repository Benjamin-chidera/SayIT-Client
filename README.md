# SayIT

A simple and interactive SayIT lication built with React and TypeScript. This app allows users to draw on a canvas, clear their drawings, undo strokes, and customize settings like language preferences.

## Features

- **Canvas Drawing**: Draw freely on the canvas with smooth strokes.
- **Undo and Clear**: Undo the last stroke or clear the entire canvas.
- **Responsive Design**: Works seamlessly across devices and screen sizes.
- **Language Selection**: Change the app's language from the settings menu.
- **High-DPI Support**: Optimized for high-resolution screens.

## Tech Stack

- **Frontend**: Next.js 16, TypeScript
- **Styling**: Tailwind CSS
- **State Management**: React Hooks

## Installation

1. Clone the repository:

cd canvas-drawing-app

npm install

npm run dev

## Usage

Open the app in your browser at http://localhost:3000.
Start drawing on the canvas.
Use the Undo and Clear buttons at the bottom of the canvas to manage your drawings.
Change the app's language from the settings menu.

## Project Structure

Canvas.tsx: Handles the drawing functionality and canvas interactions.
Settings.tsx: Manages app settings, including language selection.
App.tsx: Main entry point of the application.
